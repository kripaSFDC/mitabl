**Generated:** 2026-03-14 | **Scan Level:** Exhaustive | **Part:** backend

## Prerequisites

- PHP 8.2+
- Composer 2.x
- MySQL 8.0 (or Docker)
- Redis 7.x (or Docker)
- Node.js (for asset compilation via Laravel Mix)

---

## Local Setup (Without Docker)

```bash
cd backend
cp .env.example .env
composer install
php artisan key:generate
php artisan jwt:secret
php artisan migrate --force
php artisan db:seed
php artisan serve --host=0.0.0.0 --port=8000
```

### Optional Workers
```bash
php artisan horizon        # Queue worker with dashboard
php artisan queue:work     # Simple queue worker
php artisan schedule:work  # Task scheduler
```

---

## Local Setup (With Docker)

From project root:
```bash
docker compose up --build
```

Services started:
- `backend` on port 8000 (auto-migrates + seeds)
- `queue-worker` (Horizon)
- `scheduler` (schedule:work)
- `db` (MySQL) on port 3306
- `redis` on port 6379

## Environment Variables

Key variables in `.env`:

| Variable | Description | Example |
|----------|-------------|---------|
| APP_KEY | Laravel encryption key | base64:... |
| DB_HOST | Database host | db (Docker) or 127.0.0.1 |
| DB_DATABASE | Database name | mitabl |
| DB_PASSWORD | Database password | root (dev) |
| JWT_SECRET | JWT signing secret | Generated by `jwt:secret` |
| JWT_TTL | Token lifetime (minutes) | null (dev, no expiry) |
| STRIPE_SECRET | Stripe secret key | sk_test_... |
| STRIPE_WEBHOOK_SIGNING_SECRET | Webhook verification | whsec_... |
| QUEUE_CONNECTION | Queue driver | redis |
| CACHE_DRIVER | Cache driver | redis |

## Running Tests

```bash
# Run all tests
php artisan test

# Run with coverage
composer test:coverage

# Run with coverage threshold check (80%)
composer test:coverage:check

# Run specific test file
php artisan test --filter=SupportTicketIntakeCrmEndToEndContractTest
```

### Test Structure
- `tests/Feature/` — 33 feature test files (API contracts, admin panel, permissions, CRM E2E)
- `tests/Unit/` — 13 unit test files (services, middleware, models)
- Coverage threshold: 80% enforced in CI

## Code Conventions

- **Controllers:** Thin — delegate to Services
- **Services:** Business logic lives here (OrderService, PaymentService, etc.)
- **Models:** Eloquent with relationships, scopes, accessors, observers
- **API Resources:** Transform models to JSON response shapes
- **Middleware:** Custom role-based access (customer, restaurant, api.user.active)
- **Events/Listeners:** Async operations via queued listeners
- **Naming:** Laravel conventions (PascalCase classes, snake_case DB columns)
